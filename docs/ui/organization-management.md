# 机构管理页面说明

## 页面范围

- 机构列表页
- 机构详情页
- 机构员工与床位跟进区块

## 页面目标

帮助管理层识别机构承接压力、人员密度和床位调配机会。

## 数据来源

- 机构列表接口
- 机构详情接口
- 床位摘要接口
- 员工配置摘要接口

## UI 状态

- 加载态: 机构卡片和床位摘要骨架
- 空态: 暂无机构数据
- 错误态: 详情加载失败、摘要不可用

## 关键交互

- 列表查看入住率和员工密度
- 详情页查看经理、床位、员工与 AI 跟进建议
- 从机构页进入 AI 运营中心查看承接摘要

## AI 边界

- 可做承接与调配建议
- 不直接替代经营和组织决策
