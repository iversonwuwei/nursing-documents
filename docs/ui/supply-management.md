# 物资管理页面说明

## 页面范围

- 物资列表页
- 物资详情页
- 补货摘要卡片

## 页面目标

帮助团队识别低库存风险，并形成可审批的补货建议。

## 当前详情页收口

- `/supplies/[id]` 应先呈现对象事实、库存概览和进出库台账，再把 AI 补货解释、采购跟进和帮助入口放到后置上下文区。
- 详情页继续保持人工审批边界，不把 AI 建议误导成自动采购动作。
- 如果当前对象 id 无法命中真实或本地对象，页面应显式提示对象不存在，而不是静默回退默认物资。

## 数据来源

- 物资列表接口
- 物资详情接口
- 低库存摘要接口
- 补货草案接口

## UI 状态

- 加载态: 列表表格和库存摘要骨架
- 空态: 当前无低库存物资
- 错误态: 库存加载失败、草案创建失败

## 关键交互

- 按分类、库存状态和关键词筛选
- 查看物资差额、供应商和消耗历史
- 通过 AI 入口查看补货优先级和采购摘要
- 从详情页进入模块帮助页查看补货与采购边界

## AI 边界

- 可输出补货优先级和解释
- 不直接触发正式采购审批或下单
