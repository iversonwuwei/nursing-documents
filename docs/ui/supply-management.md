# 物资管理页面说明

## 页面范围

- 物资列表页
- 物资详情页
- 补货摘要卡片

## 页面目标

帮助团队识别低库存风险，并形成可审批的补货建议。

## 数据来源

- 物资列表接口
- 物资详情接口
- 低库存摘要接口
- 补货草案接口

## UI 状态

- 加载态: 列表表格和库存摘要骨架
- 空态: 当前无低库存物资
- 错误态: 库存加载失败、草案创建失败

## 关键交互

- 按分类、库存状态和关键词筛选
- 查看物资差额、供应商和消耗历史
- 通过 AI 入口查看补货优先级和采购摘要

## AI 边界

- 可输出补货优先级和解释
- 不直接触发正式采购审批或下单
