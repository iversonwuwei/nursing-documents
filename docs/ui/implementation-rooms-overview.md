# 实施级文档：房间列表页

## 范围

覆盖房间列表页、床位摘要卡和房间状态筛选的前端实施方式。

## 用户影响

- 机构负责人需要查看床位占用、空闲和维修状态
- 护理运营需要快速定位可分配床位

## 页面入口

- 路由: `/rooms`
- 入口来源: 侧边栏房间管理、Dashboard 资源利用卡片
- 发布阶段: 先内部角色，再开放给机构运营角色

## 组件拆分

- 摘要卡片区: 总床位、已占用、可分配、维修中
- 筛选条: 机构、楼层、状态、关键词
- 房间列表区: 房间卡片 / 表格
- 床位明细弹层: 房间内床位状态和入住长者摘要

## 数据来源

| 区块 | 数据源 | 加载策略 | 降级策略 |
| --- | --- | --- | --- |
| 摘要卡片 | 床位分配摘要接口 | 首屏请求 | 显示上次快照 |
| 房间列表 | 房间列表接口 | 与摘要并行 | 显示只读列表 |
| 床位明细弹层 | 房间详情接口 | 按需加载 | 隐藏床位建议 |

## 状态设计

- 加载态: 摘要卡片先行骨架，列表分段补齐
- 空态: 新机构无房间时展示引导创建文案
- 错误态: 摘要失败时列表仍可浏览
- 移动端: 摘要改 2 列卡片，列表支持横向滚动

## 事件与埋点

- `rooms_page_loaded`
- `rooms_filter_changed`
- `rooms_bed_detail_opened`
- `rooms_resource_card_clicked`

## 发布门禁

- 房间页与 Dashboard 床位数字一致
- 床位明细弹层能正确展示占用状态
- 降级快照模式下不出现空白摘要卡片

## 回滚方案

1. 床位摘要切回静态快照。
2. 隐藏床位建议与分配引导。
3. 保持房间列表和房间详情可访问。
