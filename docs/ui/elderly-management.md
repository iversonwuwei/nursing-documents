# 长者管理页面说明

## 页面范围

- 长者列表页
- 长者详情页
- 入住办理页
- 探视记录页

## 页面目标

统一管理长者基础信息、入住状态、家属信息和跨模块跳转入口。

## 数据来源

- 长者列表接口
- 长者详情接口
- 入住档案接口
- 探视记录接口

## UI 状态

- 加载态: 列表骨架屏、详情摘要占位
- 空态: 无长者数据或无探视记录
- 错误态: 获取详情失败、入住档案加载失败

## 关键交互

- 列表页支持搜索、筛选、进入详情
- 详情页显示基础档案、护理等级、风险标签和关联模块入口
- 入住办理页强调人工确认护理等级

## AI 边界

- 允许显示长者摘要和风险提示
- 不允许 AI 直接改写护理等级或入住状态
