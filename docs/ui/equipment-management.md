# 设备管理页面说明

## 页面范围

- 设备列表页
- 设备详情页
- 设备监控页
- 设备状态页

## 页面目标

围绕设备状态、维保和巡检优先级，保障关键设备持续可用。

## 数据来源

- 设备列表接口
- 设备详情接口
- 监控状态接口
- 设备告警接口
- 巡检结果接口

## UI 状态

- 加载态: 设备卡片、告警列表和状态摘要骨架
- 空态: 无设备告警或无异常设备
- 错误态: 监控状态加载失败、巡检提交失败

## 关键交互

- 列表筛选设备分类和状态
- 详情查看维保、位置和历史告警
- 从设备列表或状态页进入 AI 巡检建议和日志页

## AI 边界

- 可提示巡检优先级、备用方案和风险摘要
- 不直接修改设备正式状态或跳过人工巡检
