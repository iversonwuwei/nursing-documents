# 房间与床位页面说明

## 当前交付边界

- 本轮真实化范围仅覆盖 `/rooms`、`/rooms/new`、`/rooms/[id]`。
- 页面不再读取 `master-data-workflow` 的房间草稿或本地 AI room helper 作为事实源。
- 新建房间的机构归属改为读取真实已启用机构列表，不再接受自由文本机构录入。

## 页面范围

- 房间列表页
- 房间新建页
- 房间详情页
- 床位承接摘要区块

## 页面目标

通过房间、床位和机构视角支持入住承接与空间资源管理。

## 数据来源

- 房间列表接口
- 房间新建接口
- 房间详情接口
- 房间启用接口
- 老人主档列表中的房间号聚合结果，用于补充床位入住对象

## UI 状态

- 加载态: 房间卡片、表格和利用率摘要骨架
- 空态: 暂无房间数据或无可入住结果
- 错误态: 详情加载失败、状态更新失败

## 关键交互

- 列表按状态和名称筛选
- 新建房间后进入待启用闭环，并从列表或详情手工启用
- 查看房间占用率、设施和住户信息
- 通过 AI 卡片进入承接和排房建议页

## AI 边界

- 可做空床、承接压力和排房顺序建议
- 不直接替代人工排房决策
- live 模式下 AI 摘要由页面基于真实房间数据派生，不再读取本地 mock AI 数据
