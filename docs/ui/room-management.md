# 房间与床位页面说明

## 页面范围

- 房间列表页
- 房间详情页
- 床位承接摘要区块

## 页面目标

通过房间、床位和机构视角支持入住承接与空间资源管理。

## 数据来源

- 房间列表接口
- 房间详情接口
- 床位分配摘要接口

## UI 状态

- 加载态: 房间卡片、表格和利用率摘要骨架
- 空态: 暂无房间数据或无可入住结果
- 错误态: 详情加载失败、状态更新失败

## 关键交互

- 列表按状态和名称筛选
- 查看房间占用率、设施和住户信息
- 通过 AI 卡片进入承接和排房建议页

## AI 边界

- 可做空床、承接压力和排房顺序建议
- 不直接替代人工排房决策
