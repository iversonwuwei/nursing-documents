# 流程级文档：设备详情页交互流程

## 场景目标

帮助后勤人员从设备详情查看状态、维保记录并完成巡检跟进。

## 主流程

1. 用户进入设备详情页。
2. 页面加载设备基础信息、告警和维保记录。
3. 用户查看 AI 跟进建议。
4. 用户决定提交巡检结果或跳转日志页追溯。
5. 系统记录巡检结果并刷新状态。

## 分支流程

### 当前存在高风险告警

1. 页面高亮展示异常状态。
2. 提示优先检查电量、信号或备用方案。
3. 用户按优先级完成巡检。

### 无维保记录

1. 页面展示空态。
2. 提示补录维保计划或历史记录。

## 埋点建议

## 测试清单

- 详情页状态与列表页一致
- 巡检提交后状态刷新正常
- AI 建议不替代人工巡检
