# 页面级文档：定点机构协同页

## 交付约束

- scope: 把 `/organizations/partners` 收口成“协同总览 + 对象展开 + 后置边界”的 Fluent 协同页，并补足显式帮助承接面。
- affected users: 评估主管、机构运营、协同机构管理人员、第三方服务协同人员。
- changed behavior: 页面继续区分评估机构和护理服务机构，但主区先承接协同池和对象展开，场景说明、协同边界和帮助入口后置。
- dependent systems: `master-data-workflow`、`resource-workflow`、scene query 透传、定点机构帮助页。
- verification: `npm run docs:build`、admin `npm run lint` 与 `npm run build`；手工检查机构与居家两个 scene 的优先分区、对象展开和跳转。
- rollback: 回退页面编排、帮助页和本文件，不改机构类型或 scene 语义。

## 页面目标

帮助评估主管和协同运营先判断当前场景下需要优先关注哪类定点机构，再展开具体机构，查看协同范围、关联人员和后续入口。

## 主要区块

- 场景化协同总览卡
- 定点机构 KPI
- 评估机构 / 护理服务机构对象池
- 后置上下文区：当前选中机构摘要、协同边界、帮助入口

## 数据来源

- 定点机构主数据：`master-data-workflow`
- 第三方人员与护工关联：`resource-workflow`
- scene 上下文：query `scene=institutional|home`

## 状态设计

- 加载态: 当前为本地同步协同池；场景切换时页面结构保持稳定。
- 空态: 某一类机构为空时，保留另外一类机构和新增入口，不渲染空白页。
- 错误态: 机构类型、启用状态与关联人员口径不一致时需在对象展开区显式提示。
- Mobile impact: 机构卡片、对象展开与上下文区按单列堆叠，不并排展示多块说明卡。

## 关键动作

- 新增定点机构
- 展开查看机构协同细节
- 启用待启用机构
- 跳转认定中心或关联人员页继续处理

## 帮助边界

- 页面内仅保留当前场景摘要、机构边界和帮助入口。
- 评估机构与护理服务机构的完整协同口径迁移到显式帮助页，不在首屏重复展开长说明。
