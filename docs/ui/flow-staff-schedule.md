# 流程级文档：排班管理页交互流程

## 场景目标

支持主管完成班次查看、冲突识别、人工调班和覆盖风险确认。

## 主流程

1. 用户进入排班管理页。
2. 页面加载班次统计和排班表格。
3. 用户查看关键岗位缺口和 AI 覆盖建议。
4. 用户发起调班操作。
5. 系统提交更新并刷新排班表。

## 分支流程

### 排班冲突

1. 更新接口返回冲突。
2. 页面展示冲突提示。
3. 用户修改班次或更换责任人后重试。

### 覆盖风险较高

1. 页面高亮关键岗位。
2. 用户进入 AI 推理或日志页看上下文证据。
3. 人工确认后再调班。

## 埋点建议

- `schedule_edit_opened`
- `schedule_update_submitted`
- `schedule_conflict_shown`

## 测试清单

- 更新成功后页面刷新正确
- 冲突时提示清晰
- AI 建议不直接改写排班
