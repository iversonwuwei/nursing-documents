# 流程级文档：报警中心页交互流程

## 场景目标

让值班人员在报警页完成识别、接单、升级判断和日志追踪。

## 主流程

1. 用户进入报警中心。
2. 页面加载报警统计与报警列表。
3. 用户查看某条报警的解释摘要和建议动作。
4. 用户决定接单、升级或进入详情。
5. 如需追溯，跳转 AI 日志页查看历史记录。

## 分支流程

### 无待处理报警

1. 页面展示空态。
2. 保留已处理记录入口。

### 报警升级

1. 用户进入详情页或规则页。
2. 查看升级建议和人工边界。
3. 手动确认后进入正式事件链路。

## 埋点建议

- `alert_claim_clicked`
- `alert_ai_log_clicked`
- `alert_escalate_clicked`

## 测试清单

- 待处理与已处理筛选正常
- AI 建议不直接执行升级
- 跳转日志页时上下文准确
