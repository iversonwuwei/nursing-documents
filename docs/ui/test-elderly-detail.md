# 测试与验收文档：长者详情页

## 验收目标

确认长者详情页能稳定展示基础档案、护理状态和跨模块入口。

## 用例矩阵

| 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 详情展示 | 长者存在 | 打开详情页 | 基础信息完整展示 |
| 护理等级展示 | 护理等级存在 | 查看摘要 | 护理等级与标签显示正确 |
| 家属信息展示 | 家属信息存在 | 查看联系人区 | 联系人信息可见 |
| 跳健康页 | 健康入口存在 | 点击入口 | 进入健康相关页面 |
| 跳 AI 中心 | AI 入口存在 | 点击入口 | 上下文准确传递 |

## 异常路径

- 长者不存在
- 家属信息为空
- AI 入口参数缺失

## 埋点校验

- `elderly_detail_loaded`
- `elderly_health_clicked`
- `elderly_ai_entry_clicked`

## 回归清单

- 基础信息完整
- 风险标签渲染正常
- 相关入口跳转无误
