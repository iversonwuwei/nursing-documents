# 健康监测页面说明

## 页面范围

- 健康监测列表页
- 长者健康趋势页
- 健康异常说明区块

## 页面目标

帮助护理团队快速识别高风险对象，并对异常指标做解释和人工复核。

## 数据来源

- 健康监测列表接口
- 趋势接口
- 异常提醒接口
- AI 解释结果接口

## UI 状态

- 加载态: 体征卡片和趋势图骨架屏
- 空态: 当前无异常对象
- 错误态: 趋势数据获取失败、解释结果不可用

## 关键交互

- 按风险等级排序和筛选
- 查看单个长者体征趋势与解释
- 从健康页跳入 AI 推理或日志审计页

## AI 边界

- AI 只输出解释、风险和下一步动作
- 不直接触发诊疗动作或关闭高风险事件
