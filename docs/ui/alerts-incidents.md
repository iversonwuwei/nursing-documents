# 报警与事件页面说明

## 页面范围

- 报警中心
- 事故列表页
- 事故详情页

## 页面目标

管理报警、事件、处理进度和复盘结论，确保处理链路可追踪。

## 数据来源

- 报警列表接口
- 事件列表接口
- 事件详情接口
- 处理动作接口
- 复盘结果接口

## UI 状态

- 加载态: 报警卡片和事件表格骨架
- 空态: 暂无报警或事件记录
- 错误态: 详情加载失败、处理动作提交失败

## 关键交互

- 列表按等级、状态和时间筛选
- 详情页展示时间线、责任人、处理动作和结案检查项
- 可从列表页进入 AI 复盘与日志页

## AI 边界

- 可提供解释、升级建议和复盘摘要
- 不允许自动结案或替代正式事故认定
