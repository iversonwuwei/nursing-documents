# 页面级文档：健康监测页

## 页面目标

按风险优先级展示监测对象，帮助护理团队识别高风险并组织复核；主工作区优先保留当班动作，解释型内容后置到信息轨。

## 主要区块

- 总览与 KPI 卡片
- 当班跟进动作板
- 趋势图与监测对象列表
- 右侧 AI 风险解释 / 趋势解读 / 帮助入口

## 数据来源

- 健康监测列表接口
- 异常解释接口

## 状态设计

- 加载态: 列表卡片骨架
- 空态: 异常视图下当前无异常对象，需显式显示零结果空态
- 错误态: 列表、趋势图或解释加载失败时局部降级，避免整页不可用

## 关键动作

- 通过全部/异常切换调整主工作区对象集合
- 先处理跟进动作板中的重点对象，再查看趋势图与单个对象体征卡
- 从右轨跳转 AI 推理页、日志页和帮助页
