# 我的页交付说明

## 范围

- 变更名称：我的页交付说明补齐与服务入口稳定化
- 页面或路由入口：根 Tab “我的”
- 影响用户：通过“我的服务”进入消息、账单、报警历史和护理反馈的家属端用户
- 发布阶段：原型工程内默认开启

## 用户影响

- “我的”页继续承担账户摘要和服务矩阵入口的聚合角色。
- 服务动作项具备稳定锚点，可验证从“我的”页进入次级页面的链路。
- 不变行为：当前仍是只读聚合页，不引入用户设置、真实账户编辑和鉴权刷新。

## 数据或 Mock 来源

- 当前数据来源：`MockFamilyService.currentElder`
- 当前边界：仅展示家属端身份和服务矩阵摘要，不接入真实账户中心
- 后续替换路径：可由账户服务或 BFF 替换 `MockFamilyService`

## UI 状态

- 加载态：当前为本地 Mock，同步渲染
- 空态：当前服务矩阵固定，不单独拆分空态
- 错误态：当前无远程请求，仍以聚合展示为主
- 手机端影响：保留纵向服务矩阵布局

## 可观测性与健康信号

- 健康信号：“我的”页可进入、服务矩阵可见、动作项可跳转到次级页
- 失败信号：服务动作项缺失、点击无响应、服务状态 rail 不可见
- 稳定验证锚点：服务动作项 key

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：从“我的”页进入消息、账单或报警历史再返回

## 回滚

- 可直接回退到无稳定动作锚点的原始实现
- 不涉及路由、权限或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：当前未覆盖真实账户绑定关系、消息总数或服务状态回流
- 未验证项：未接入真实账户接口、通知计数和设置管理
