# 账单页交付说明

## 范围

- 变更名称：家属端账单页筛选与空态兜底
- 页面或路由入口：`/bills`
- 影响用户：从首页快捷入口或“我的服务”进入账单中心的家属端用户
- 发布阶段：原型工程内默认开启

## 用户影响

- 用户现在可以按账单状态查看待支付或已支付记录，而不是只浏览固定顺序列表。
- 当账单为空或某一状态无数据时，页面会显示稳定空态并允许切回全部。
- 不变行为：账单中心仍是只读/演示态，不接真实支付和结算明细接口。

## 数据或 Mock 来源

- 当前数据来源：`MockFamilyService.bills`
- 当前边界：只展示家属端账单摘要，不暴露机构管理或财务后台字段
- 后续替换路径：可由 BFF 或真实结算 API 替换 `MockFamilyService`

## UI 状态

- 加载态：当前为本地 Mock，同步渲染，不单独展示骨架屏
- 空态：新增“当前没有账单记录”卡片，并支持恢复全部状态
- 错误态：当前无远程请求，仍以只读兜底和提示文案为主
- 手机端影响：沿用单列卡片布局，不改变现有家属端手机优先信息密度

## 页面状态稳定性

- 状态筛选使用页面内状态，不影响主 Tab Shell 的 IndexedStack 策略
- 重新进入页面时，筛选回到“全部”，保持行为简单可预测
- 账单排序优先展示待支付记录，再按到期日排序，符合家属端处理优先级

## 可观测性与健康信号

- 健康信号：页面可进入、待支付统计正确、状态筛选可切换、空态可恢复
- 失败信号：页面白屏、待支付金额统计错误、筛选切换后列表不更新、空态不可恢复
- 稳定验证锚点：账单卡片 key、筛选 key、空态 key

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：从首页和“我的服务”进入账单页，切换“待支付/已支付”并验证列表变化

## 回滚

- 可直接回退到无筛选的原始账单列表实现
- 若真实支付链路后续不稳定，可继续保留当前只读演示模式
- 不涉及路由、权限或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：当前排序依赖原型账单日期字符串可被 `DateTime.tryParse` 解析
- 未验证项：未接入真实支付回执、账单分页、退款或失败重试链路
