# 健康页交付说明

## 范围

- 变更名称：健康页交付说明补齐与 AI 说明入口锚点
- 页面或路由入口：根 Tab “健康”
- 影响用户：查看体征趋势和健康解释的家属端用户
- 发布阶段：原型工程内默认开启

## 用户影响

- 健康页继续承担体征趋势和家属友好解释的主页面角色。
- AI 说明入口现在具备稳定锚点，可验证健康页到 AI 今日摘要页的跳转链路。
- 不变行为：趋势图和说明仍基于原型数据，不引入实时医疗判断。

## 数据或 Mock 来源

- 当前数据来源：`MockFamilyService.vitalMetrics`
- 当前边界：仅展示家属可理解的趋势与解释，不暴露医学级诊疗字段
- 后续替换路径：可由健康监测 API 或 BFF 替换 `MockFamilyService`

## UI 状态

- 加载态：当前为本地 Mock，同步渲染
- 空态：当前未拆分趋势空态，后续接真实接口时需补齐
- 错误态：当前无远程请求，仍以原型展示为主
- 手机端影响：保留单列趋势卡片和说明卡布局

## 可观测性与健康信号

- 健康信号：健康页可进入、趋势卡可见、AI 说明入口可跳转
- 失败信号：趋势卡缺失、说明区不可见、AI 入口无法打开
- 稳定验证锚点：健康页 AI 入口 key

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：从健康页进入 AI 今日摘要并返回

## 回滚

- 可直接回退到无稳定锚点的原始实现
- 不涉及路由、权限或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：当前未覆盖真实健康接口为空、延迟或异常数据格式场景
- 未验证项：未接入真实趋势查询、分页和更长时间窗分析
