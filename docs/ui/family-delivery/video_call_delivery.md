# 视频入口与导航链路交付说明

## 范围

- 变更名称：家属端视频页稳定锚点与入口链路验证
- 页面或路由入口：`/video-call`，以及首页、探视页、我的服务等聚合入口的导航链路
- 影响用户：需要从聚合入口进入视频沟通、消息中心或报警历史的家属端用户
- 发布阶段：原型工程内默认开启

## 用户影响

- 视频页的通话目的选择和发起动作现在具备稳定锚点，可用于自动化验证。
- 首页快捷入口、我的服务入口到次级页的链路现在可通过测试确认，而不是只依赖人工点击。
- 不变行为：视频沟通仍是演示态，不接入真实通话建立与状态回执。

## 数据或 Mock 来源

- 当前数据来源：`MockFamilyService.currentElder`
- 当前边界：仅覆盖家属端内的导航与演示流，不引入护理站实时接通状态
- 后续替换路径：真实视频服务、路由守卫或 BFF 接入后保留当前验证锚点

## UI 状态

- 加载态：当前为本地 Mock，同步渲染
- 空态：本次不新增视频页空态，重点放在入口锚点和导航链路验证
- 错误态：当前无远程请求，失败主要表现为导航失效或控件不可用
- 手机端影响：入口按钮和路由跳转保持现有手机端布局

## 可观测性与健康信号

- 健康信号：首页快捷入口可进入消息中心，我的服务入口可进入报警历史，探视页可进入远程视频和 AI 探视助手
- 失败信号：入口按钮失效、导航后页面标题或主内容未出现、视频页目的选择不可点击
- 稳定验证锚点：home/profile/root/visit/video 页面 key 和主标题

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：从首页、探视页和“我的服务”分别进入次级页并返回

## 回滚

- 可直接回退到无导航锚点和无链路测试的原始实现
- 不涉及路由定义、权限模型或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：当前链路验证仍基于原型路由和 Mock 数据，不代表真实服务接入后的通话状态可靠性
- 未验证项：未接入真实视频房间、接通超时、鉴权失效和弱网重试场景
