# 护理反馈页交付说明

## 范围

- 变更名称：护理反馈页评分与标签交互锚点
- 页面或路由入口：`/feedback`
- 影响用户：从“我的服务”进入护理反馈的家属端用户
- 发布阶段：原型工程内默认开启

## 用户影响

- 评分按钮、反馈标签和提交动作现在具备稳定锚点，可验证家属端反馈交互是否仍然正常。
- 不变行为：反馈页仍是原型态，不接入真实文本输入、回访工单或服务单跟踪。

## 数据或 Mock 来源

- 当前数据来源：页面内本地 GetX 状态
- 当前边界：仅处理家属端即时评分与标签选择，不持久化到远端服务
- 后续替换路径：可由正式反馈 API 或工单系统接入当前控制器

## UI 状态

- 加载态：当前无远程请求，不单独展示加载态
- 空态：当前标签集合固定，不设置空态
- 错误态：当前通过本地状态交互，不涉及远程异常
- 手机端影响：保留评分按钮 + 标签矩阵布局

## 可观测性与健康信号

- 健康信号：评分切换可见、标签可选中、已选标签计数可更新
- 失败信号：评分不变化、标签选中失效、提交按钮不可触发
- 稳定验证锚点：评分 key、标签 key、提交 key

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：切换评分、选择标签并提交一次反馈

## 回滚

- 可直接回退到无稳定锚点的原始实现
- 不涉及路由、权限或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：当前仅验证本地交互，不代表真实反馈提交通路已可靠
- 未验证项：未接入真实文本输入、附件、回访派单和审计日志
