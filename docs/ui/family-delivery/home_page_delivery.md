# 首页交付说明

## 范围

- 变更名称：家属端首页交付说明补齐与 AI 摘要入口锚点
- 页面或路由入口：根 Tab “首页”
- 影响用户：所有进入家属端首页的家属用户
- 发布阶段：原型工程内默认开启

## 用户影响

- 首页保留今日状态、护理进度、快捷入口和 AI 今日摘要的聚合总览角色。
- AI 今日摘要入口现在具备稳定锚点，可验证首页到 AI 解释页的主链路。
- 不变行为：首页仍然使用原型数据，不引入实时推送或后台轮询。

## 数据或 Mock 来源

- 当前数据来源：`MockFamilyService.currentElder`、`vitalMetrics`、`todayCareRecords`、`todayAiSummary`
- 当前边界：首页只展示家属端聚合摘要，不暴露员工或后台管理字段
- 后续替换路径：可由 BFF 或聚合查询接口替换 `MockFamilyService`

## UI 状态

- 加载态：当前为本地 Mock，同步渲染
- 空态：当前首页以聚合摘要为主，尚未引入独立空态拆分
- 错误态：当前无远程请求，仍以原型稳定展示为主
- 手机端影响：延续手机端优先的单列/横滑卡片布局

## 可观测性与健康信号

- 健康信号：首页可进入、今日状态可见、快捷入口可用、AI 今日摘要入口可跳转
- 失败信号：首页白屏、关键摘要缺失、AI 入口无法打开
- 稳定验证锚点：首页 AI 摘要入口 key

## 验证门禁

- 必跑：`flutter analyze`
- 必跑：`flutter test`
- 建议手工验证：首页进入 AI 今日摘要页并返回

## 回滚

- 可直接回退到无首页 AI 锚点的原始实现
- 不涉及路由、权限或数据迁移，回滚成本低

## 风险与未验证项

- 已知风险：首页当前没有覆盖真实服务延迟、推送刷新和接口失败场景
- 未验证项：未接入真实首页聚合 API 和增量刷新
