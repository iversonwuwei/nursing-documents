# 测试与验收文档：Dashboard 首页

## 验收目标

确认首页能稳定展示来自 Admin BFF 聚合接口的关键运营信息，且不再回退到静态演示数字。

## 用例矩阵

| 场景 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 首页加载成功 | 聚合接口可用 | 打开首页 | KPI 和摘要卡片正常显示 |
| 告警摘要展示 | 存在待处理报警 | 查看首页 | 告警模块卡片可见且数值非静态写死 |
| 通知与财务摘要展示 | 通知、账单服务可用 | 查看首页 | 通知与财务摘要区可见 |
| 员工排行展示 | 护理任务存在 | 查看首页 | 员工排行表展示真实任务统计 |
| 空态展示 | 聚合结果为空 | 打开首页 | 显示 `0` 或默认空文案 |

## 异常路径

- 聚合接口失败
- 单个摘要区块缺数据
- 下游服务部分失败导致 BFF 返回 502

## 埋点校验

- `dashboard_loaded`
- `dashboard_ai_entry_clicked`
- `dashboard_card_clicked`

## 回归清单

- KPI 数值显示正确
- `/analytics` 与 `/data-dashboard` 页面口径一致
- 页面失败时不出现旧静态数组
