# 系统概览

## 目标

建立一个面向养老护理业务的文档化系统视图，便于产品、设计、研发、测试和运营对齐边界。

## 主要角色

- 管理者：查看经营、运营和风险情况。
- 护理主管：关注老人健康、报警、任务和排班。
- 护理员：执行护理任务、补录状态、处理异常。
- 后勤与采购：处理设备、维保、物资和补货。
- 家属：查看老人状态、探视和关键通知。

## 核心模块

### 管理端

- Dashboard 与 AI 运营中心
- 长者管理
- 健康监测
- 报警与事件
- 员工、任务与排班
- 房间与机构
- 设备与物资
- 财务与报表

### 协同端

- 护理人员工作台
- 家属查看视图

## 设计原则

- AI 先建议，人再确认。
- 高风险流程必须保留人工审核和回滚路径。
- 页面文档、接口文档与发布文档保持一一对应。
- 变更优先用最小可审阅单元沉淀。

## 观测点

- 构建和类型检查结果
- 页面/模块级回归结果
- 关键流程的错误率与处理时效
- AI 建议采纳率与人工覆盖情况
