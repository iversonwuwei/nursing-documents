# 健康监测模块

## 模块目标

围绕体征、趋势、异常与解释能力，帮助护理团队快速识别健康风险并组织人工复核。

## 核心能力

- 长者健康指标列表
- 单个长者健康趋势分析
- 异常指标高亮
- 报警前置解释与 AI 建议
- 复测、复核和升级建议留痕

## 关键流程

1. 接收健康监测数据。
2. 识别异常组合和高风险对象。
3. 输出解释、建议与下一步动作。
4. 由医护人员人工确认是否复测、复核或升级报警。

## 验收方向

- 页面可按风险优先级查看异常对象。
- 推理结果必须附带解释和下一步动作。
- 高风险场景不允许自动关闭或自动定级。

## 边界说明

- 该模块不替代医生诊断。
- AI 只做解释和建议，不直接执行医疗操作。
