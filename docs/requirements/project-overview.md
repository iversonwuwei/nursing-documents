# 护理项目需求概览

## 背景

该项目面向养老护理场景，目标是沉淀管理端、护理执行端和家庭协同端的数字化能力，覆盖老人档案、健康监测、报警处理、员工协同、房间与床位管理、设备与物资管理等核心模块。

## 目标

- 建立统一的养老护理业务管理后台。
- 支持老人全生命周期档案与健康跟踪。
- 提供报警、任务、排班、设备、物资等日常运营支持。
- 为 AI 解释、建议与治理能力预留清晰边界。

## 范围

- Admin 管理端页面与运营能力。
- APP 端的护理人员与家属协同视图。
- 健康、事件、设备、物资、机构、员工等核心业务模块。
- 需求、设计、接口、运维与发布文档沉淀。

## 非目标

- 不在本阶段定义真实生产基础设施。
- 不在本阶段引入自动化执行型 AI 决策。

## 关键模块

- 长者档案与入住管理
- 健康监测与异常解释
- 报警中心与事件复盘
- 员工管理、任务与排班
- 房间、床位、机构管理
- 设备、物资与巡检跟进
- AI 运营中心与规则治理

## 验收方向

- 文档目录结构清晰，团队可以按主题持续沉淀。
- 关键模块均有对应文档入口。
- 发布、回滚、观察指标有明确记录位置。
