# 房间与床位模块

## 当前交付边界

- 本轮先把房间主档切到真实后端，只覆盖房间列表、房间新建、房间详情和人工启用闭环。
- 房间机构归属现已切到真实 organizations 主档选择器，提交时同时保存 `organizationId` 与 `organizationName` 作为真实引用与冗余展示字段。
- 床位入住对象优先从真实老人主档的 `RoomNumber` 聚合读取；没有匹配住户时保持空床，而不是回退前端 mock occupant。

## 模块目标

围绕房间、床位与承接能力，支撑入住分配和空间资源管理。

## 核心能力

- 房间列表与状态查看
- 可入住房间识别
- 床位使用率与分院承接能力查看
- 房间详情、清洁状态和设施状态
- AI 排房与承接建议

## 关键流程

1. 查看房间和床位占用情况。
2. 识别空房、空床和待维护房间。
3. 结合护理等级和机构状态做入住分配。
4. 对承接压力较高的区域做人工协调。

## 验收方向

- 页面能清晰展示可入住、已满、维护中等状态。
- 房间与机构、长者、入住流程之间有明确关联。
- 新建房间提交后进入待启用，启用前不应计入可入住资源池。
- AI 只做排序和建议，不直接完成排房。

## 边界说明

- 不替代正式入住分配审批。
- 不把床位统计当作唯一决策依据。
- 房间建档必须选择已启用机构；若机构还未建档或未启用，应先完成机构主档闭环。
