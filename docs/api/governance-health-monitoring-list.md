# 治理级文档：健康监测列表查询

## 范围

面向健康监测页、Dashboard 健康卡片和 AI 推理入口，定义健康监测列表查询的运行治理、发布门禁与回滚策略。

## 入口与调用方

- 方法: `GET`
- 路径: `/api/health/monitoring`
- 主要调用方: 健康监测页、Dashboard 健康风险卡片、AI 推理入口
- 发布阶段: 先管理端全量，再开放给机构运营角色

## 依赖边界

- 主数据源: 健康监测结果表
- 扩展依赖: 风险评估规则、长者主档、AI 摘要生成服务
- 约束: 只负责查询与排序，不做风险状态写回

## 成功判据

- 高风险对象可稳定排在列表前列
- Dashboard 与监测页口径一致
- `aiSummary` 缺失时页面能降级但不阻断列表展示

## 运行健康信号

- SLI: `p95_latency < 400ms`
- SLI: 成功率 `>= 99.5%`
- 业务指标: 高风险对象排序偏差 `= 0`
- 业务指标: AI 摘要缺失占比 `< 5%`

## 失败模式

- `400`: 筛选参数非法
- `403`: 访问权限不足
- `500`: 监测结果聚合失败
- 降级策略: 仅返回基础监测字段，隐藏 AI 摘要与解释入口

## 日志与监控

- 结构化日志字段: `riskLevel`、`organizationId`、`keyword`、`resultCount`、`degraded`
- 监控图表: 查询耗时、高风险数量、AI 摘要缺失率
- 告警建议: 10 分钟内高风险对象缺失或排序异常时触发 P1 告警

## 兼容性策略

- 新增监测字段只能追加
- `riskLevel` 枚举扩展需同步监测页颜色和排序规则
- `aiSummary` 继续保持可空

## 验证门禁

- 契约测试覆盖高风险、中风险、无结果和 AI 摘要为空场景
- 页面联调验证 Dashboard 与健康监测页口径一致
- 发布前检查高风险对象抽样比对结果

## 回滚路径

1. 关闭 AI 摘要服务依赖。
2. 监测页退回基础列表模式。
3. Dashboard 隐藏健康 AI 摘要入口。
