# 健康监测 API 草案

## 模块用途

服务健康列表、趋势分析、异常解释和复测建议。

## 建议接口

### 查询健康监测列表

- 方法: `GET`
- 路径: `/api/health/monitoring`
- 用途: 按风险、机构、房间、长者筛选监测对象

### 查询单个长者健康趋势

- 方法: `GET`
- 路径: `/api/health/monitoring/:elderlyId/trends`
- 用途: 返回体温、血压、血氧等时间序列

### 查询异常提醒

- 方法: `GET`
- 路径: `/api/health/alerts`
- 用途: 返回异常指标、高风险组合与建议动作

### 查询健康解释结果

- 方法: `GET`
- 路径: `/api/health/explanations/:elderlyId`
- 用途: 返回 AI 解释、置信度、建议复测动作

## 调用方

- 健康监测页
- 长者详情健康区块
- AI 推理页

## 兼容性

- 趋势数据应允许新指标追加。
- AI 解释字段需允许为空，避免强依赖 AI 服务可用性。

## 回滚说明

如解释结果异常，可回退为只展示原始体征与人工备注。
