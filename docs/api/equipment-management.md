# 设备管理 API 草案

## 模块用途

服务设备列表、监控状态、告警、维保和巡检建议。

## 建议接口

### 查询设备列表

- 方法: `GET`
- 路径: `/api/equipment`
- 用途: 返回设备分类、位置、状态、维保日期

### 查询设备详情

- 方法: `GET`
- 路径: `/api/equipment/:equipmentId`
- 用途: 获取单台设备详情、历史告警和维保记录

### 查询设备监控状态

- 方法: `GET`
- 路径: `/api/equipment/monitoring`
- 用途: 返回信号、电量、在线状态和最近告警

### 查询设备告警

- 方法: `GET`
- 路径: `/api/equipment/alarms`
- 用途: 返回待处理、处理中、已恢复告警

### 提交巡检结果

- 方法: `POST`
- 路径: `/api/equipment/:equipmentId/patrols`
- 用途: 记录巡检动作、恢复情况和备用方案

## 调用方

- 设备列表页
- 设备详情页
- 设备监控页
- AI 推理与日志页

## 兼容性

- 监控状态字段需要支持后续增加更多指标。
- 告警接口建议允许分页和增量拉取。

## 回滚说明

如监控或巡检写入链路异常，可回退为只读告警和人工巡检记录。
