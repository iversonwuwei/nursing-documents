# 物资管理 API 草案

## 模块用途

服务库存列表、低库存提醒、物资详情和补货建议。

## 建议接口

### 查询物资列表

- 方法: `GET`
- 路径: `/api/supplies`
- 用途: 返回分类、库存、安全线、供应商和状态

### 查询物资详情

- 方法: `GET`
- 路径: `/api/supplies/:supplyId`
- 用途: 获取消耗记录、补货历史和供应商信息

### 查询低库存摘要

- 方法: `GET`
- 路径: `/api/supplies/low-stock-summary`
- 用途: 返回缺口、紧急程度和建议补货顺序

### 创建补货建议单

- 方法: `POST`
- 路径: `/api/supplies/restock-drafts`
- 用途: 生成待审批的补货草案

## 调用方

- 物资列表页
- 物资详情页
- 报表或 AI 运营页

## 兼容性

- 安全库存字段需支持不同物资类别独立规则。
- 补货建议单应与正式采购单区分。

## 回滚说明

如补货草案生成异常，可回退为只展示库存差额和人工线下审批。
