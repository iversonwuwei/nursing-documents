# 治理级文档：长者详情查询

## 范围

面向长者详情页、探视记录页和 AI 推理页，定义长者详情查询接口的运行治理要求、健康信号与回滚策略。

## 入口与调用方

- 方法: `GET`
- 路径: `/api/elderly/:id`
- 主要调用方: 长者详情页、探视记录侧栏、AI 运营中心实体追踪
- 发布阶段: 内部管理端全量开放

## 依赖边界

- 主数据源: 长者主档表
- 扩展依赖: 最近探视记录、护理等级、风险标签聚合服务
- 禁止职责: 不在该接口中执行写操作或自动修正长者资料

## 成功判据

- 详情页首屏可在 1 次请求内返回基础信息与风险摘要
- `riskLevel`、`careLevel`、`latestVisitAt` 字段齐全时，前端无需二次拼装
- AI 页从长者详情跳转后可复用同一实体标识

## 运行健康信号

- SLI: `p95_latency < 450ms`
- SLI: 成功率 `>= 99.5%`
- 业务指标: 缺失风险标签占比 `< 1%`
- 业务指标: 空白详情页占比 `< 0.5%`

## 失败模式

- `404`: 长者不存在或已归档
- `409`: 长者状态变更导致资料暂不可读
- `500`: 明细聚合失败
- 降级策略: 仅返回基础资料与最新状态，隐藏探视记录与 AI 摘要区块

## 日志与监控

- 结构化日志字段: `elderlyId`、`organizationId`、`riskLevel`、`caller`、`degraded`
- 监控图表: 详情查询耗时、404 比例、聚合降级比例
- 告警建议: 5 分钟内 500 比例超过 2% 时触发 P2 告警

## 兼容性策略

- 新增可选字段允许前端忽略
- `riskLevel` 枚举扩展前需同步 UI 标签映射
- `latestVisitAt` 允许为空，不作为失败条件

## 验证门禁

- 契约测试覆盖基础资料、带探视记录、降级返回三类响应
- 页面联调验证详情页和 AI 运营中心跨页跳转
- 发布前检查监控面板与告警规则已生效

## 回滚路径

1. 关闭扩展聚合逻辑，仅保留基础资料查询。
2. 前端隐藏探视记录与 AI 摘要卡片。
3. 保持原有详情页可读，后续再逐步恢复聚合字段。
