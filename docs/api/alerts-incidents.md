# 报警与事件 API 草案

## 模块用途

服务报警列表、事件详情、处理动作与复盘记录。

## 建议接口

### 查询报警列表

- 方法: `GET`
- 路径: `/api/alerts`
- 用途: 按等级、状态、来源筛选报警

### 查询事件列表

- 方法: `GET`
- 路径: `/api/incidents`
- 用途: 返回事故记录、状态、责任人和时间线摘要

### 查询事件详情

- 方法: `GET`
- 路径: `/api/incidents/:incidentId`
- 用途: 获取事件经过、处理动作、复核状态

### 提交处理动作

- 方法: `POST`
- 路径: `/api/incidents/:incidentId/actions`
- 用途: 记录接单、升级、复核、结案备注

### 查询复盘结果

- 方法: `GET`
- 路径: `/api/incidents/:incidentId/retrospective`
- 用途: 获取复盘摘要、预防措施和后续跟进项

## 调用方

- 报警中心
- 事故列表和详情页
- AI 日志与规则治理页

## 兼容性

- 动作记录建议设计为 append-only，避免覆盖历史。
- 事件状态枚举需要保留扩展能力。

## 回滚说明

如新增处理动作链路不稳定，可回退为只读事件流和人工线下记录。
