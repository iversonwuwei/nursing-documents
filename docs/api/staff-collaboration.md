# 员工协同 API 草案

## 模块用途

服务员工列表、任务中心、排班管理和覆盖风险查看。

## 建议接口

### 查询员工列表

- 方法: `GET`
- 路径: `/api/staff`
- 用途: 返回员工、岗位、部门、状态和联系方式

### 查询任务列表

- 方法: `GET`
- 路径: `/api/staff/tasks`
- 用途: 返回任务状态、优先级、责任人和 SLA 信息

### 查询排班列表

- 方法: `GET`
- 路径: `/api/staff/schedule`
- 用途: 返回班次安排、休假和补位情况

### 更新排班

- 方法: `PUT`
- 路径: `/api/staff/schedule/:scheduleId`
- 用途: 调整班次和责任人

### 查询覆盖风险摘要

- 方法: `GET`
- 路径: `/api/staff/coverage-summary`
- 用途: 返回关键岗位缺口和 AI 辅助说明

## 调用方

- 员工列表页
- 员工详情页
- 任务中心
- 排班管理页

## 兼容性

- 任务优先级和排班班次应保持稳定枚举。
- 覆盖风险摘要建议弱依赖 AI，可降级为空数据。

## 回滚说明

如排班更新链路异常，回退为只读排班展示和人工线下调整。
