# 接口级文档：排班更新

## 基本信息

- 方法: `PUT`
- 路径: `/api/staff/schedule/:scheduleId`
- 说明: 更新排班班次、责任人或备注。

## 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| scheduleId | string | 是 | 排班记录 ID |

## 请求体示例

```json
{
  "staffId": "S001",
  "shift": "夜班",
  "date": "2026-03-31",
  "remark": "补位调整"
}
```

## 响应示例

```json
{
  "success": true,
  "scheduleId": "SCH001",
  "updatedAt": "2026-03-30 11:20"
}
```

## 错误码

- `400`: 请求体不完整或班次非法
- `409`: 排班冲突
- `500`: 排班更新失败

## 调用页面

- 排班管理页
- 主管排班调整弹层
