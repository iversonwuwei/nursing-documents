# 治理级文档：床位分配摘要

## 范围

面向房间列表页、床位概览卡和机构看板，定义床位分配摘要接口的发布安全、观测与回滚要求。

## 入口与调用方

- 方法: `GET`
- 路径: `/api/rooms/allocation-summary`
- 主要调用方: 房间列表页、Dashboard 资源利用卡片、机构详情页
- 发布阶段: 先管理端灰度，再扩展到机构大屏

## 依赖边界

- 主数据源: 房间与床位资源表
- 扩展依赖: 入住状态聚合、维修占用状态表
- 约束: 不直接变更床位状态，仅返回汇总与分配建议

## 成功判据

- 页面可一次获取总床位、已占用、可用、维修中四类指标
- Dashboard 与房间页展示口径一致
- 空机构或新机构能返回稳定空态结果

## 运行健康信号

- SLI: `p95_latency < 300ms`
- SLI: 成功率 `>= 99.8%`
- 业务指标: 汇总口径偏差数 `= 0`
- 业务指标: 空态机构识别准确率 `= 100%`

## 失败模式

- `400`: 机构筛选参数非法
- `503`: 汇总服务不可用
- 降级策略: 房间页回退为静态总览数字，Dashboard 隐藏资源趋势

## 日志与监控

- 结构化日志字段: `organizationId`、`wardId`、`occupiedBeds`、`availableBeds`、`degraded`
- 监控图表: 汇总耗时、机构分组分布、空态机构数量
- 告警建议: 汇总偏差或空态异常时触发 P2 告警

## 兼容性策略

- 新增指标需保持旧字段不删除
- 分组维度扩展前需确认 Dashboard 卡片布局兼容
- 机构无房间时返回 0 值汇总，不返回错误

## 验证门禁

- 契约测试校验总量守恒
- 页面验证 Dashboard 与房间页数字一致
- 发布前核对监控面板和资源利用告警阈值

## 回滚路径

1. 关闭聚合计算，改用最近一次稳定快照。
2. Dashboard 卡片显示“摘要已降级”。
3. 保留房间列表功能，暂停床位建议说明。
