# 长者管理 API 草案

## 模块用途

服务长者列表、详情、入住建档、探视记录等核心流程。

## 建议接口

### 查询长者列表

- 方法: `GET`
- 路径: `/api/elderly`
- 用途: 支持按姓名、机构、护理等级、状态筛选长者列表

### 查询长者详情

- 方法: `GET`
- 路径: `/api/elderly/:elderlyId`
- 用途: 获取基础信息、护理等级、家属信息、风险标签

### 创建或更新入住档案

- 方法: `POST` / `PUT`
- 路径: `/api/elderly/:elderlyId/admission`
- 用途: 保存入住评估、护理等级、房间和床位绑定信息

### 查询探视记录

- 方法: `GET`
- 路径: `/api/elderly/:elderlyId/visits`
- 用途: 获取探视时间、访客信息、沟通备注

## 调用方

- Admin 长者列表页
- Admin 长者详情页
- 入住办理页
- 探视记录页

## 兼容性

- 护理等级字段应保留可扩展枚举。
- 家属信息和风险标签建议作为可选扩展字段。

## 回滚说明

如新字段导致页面不兼容，可先回退到最小详情结构，仅保留基础档案和入住状态。
