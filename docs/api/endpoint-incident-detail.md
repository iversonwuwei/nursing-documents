# 接口级文档：事故详情查询

## 基本信息

- 方法: `GET`
- 路径: `/api/incidents/:incidentId`
- 说明: 查询事故详情、时间线、责任人和处理状态。

## 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| incidentId | string | 是 | 事故 ID |

## 响应示例

```json
{
  "id": "I001",
  "title": "老人摔倒",
  "level": "严重",
  "status": "处理中",
  "elderlyName": "张桂英",
  "occurredAt": "2026-03-28 16:30",
  "owner": "护理主管",
  "timeline": [
    {
      "time": "2026-03-28 16:35",
      "action": "已送医处理"
    }
  ]
}
```

## 错误码

- `404`: 事故不存在
- `500`: 事故详情查询失败

## 调用页面

- 事故详情页
- AI 日志审计页上下文跳转
