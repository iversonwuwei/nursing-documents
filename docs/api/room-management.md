# 房间与床位 API 草案

## 模块用途

服务房间列表、床位占用、清洁状态和可入住判断。

## 建议接口

### 查询房间列表

- 方法: `GET`
- 路径: `/api/rooms`
- 用途: 返回房间状态、房型、机构、床位使用率

### 查询房间详情

- 方法: `GET`
- 路径: `/api/rooms/:roomId`
- 用途: 获取床位明细、住户、设施、清洁和巡检信息

### 查询床位分配摘要

- 方法: `GET`
- 路径: `/api/rooms/allocation-summary`
- 用途: 返回空房、空床、预留床和机构承接能力摘要

### 更新房间状态

- 方法: `PUT`
- 路径: `/api/rooms/:roomId/status`
- 用途: 更新维护中、可入住、已满等状态

## 调用方

- 房间列表页
- 房间详情页
- 入住相关分配页

## 兼容性

- 房间状态与清洁状态应拆分字段，避免语义混用。
- 床位信息建议支持后续扩展为独立实体。

## 回滚说明

如状态更新链路异常，可回退为只读房间视图和人工确认分配。
