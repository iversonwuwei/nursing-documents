# 治理级文档：机构详情查询

## 范围

面向机构列表页、机构详情页和 Dashboard 机构切换卡片，定义机构详情查询接口的聚合边界和观测要求。

## 入口与调用方

- 方法: `GET`
- 路径: `/api/organizations/:id`
- 主要调用方: 机构列表页、机构详情页、Dashboard 机构摘要
- 发布阶段: 管理端全量开放

## 依赖边界

- 主数据源: 机构主档表
- 扩展依赖: 床位摘要、员工摘要、设备在线率
- 约束: 机构详情只做汇总聚合，不负责资源变更写入

## 成功判据

- 机构详情页一次请求可得到基本资料与关键运营摘要
- Dashboard 机构卡与机构详情数字一致
- 新机构或停用机构均能返回稳定状态

## 运行健康信号

- SLI: `p95_latency < 420ms`
- SLI: 成功率 `>= 99.5%`
- 业务指标: 跨页口径偏差 `= 0`
- 业务指标: 停用机构错误展示率 `= 0`

## 失败模式

- `404`: 机构不存在
- `409`: 机构状态变更中
- `500`: 聚合失败
- 降级策略: 仅返回基础机构资料，隐藏运营摘要区块

## 日志与监控

- 结构化日志字段: `organizationId`、`status`、`summaryIncluded`、`degraded`
- 监控图表: 查询耗时、聚合降级率、停用机构访问量
- 告警建议: 5 分钟内聚合降级率超过 3% 时触发 P2 告警

## 兼容性策略

- 新摘要字段需保持可选
- 停用状态枚举扩展前同步前端标签映射
- 汇总数字必须与独立模块页保持同口径

## 验证门禁

- 契约测试覆盖正常机构、停用机构、聚合降级
- 页面联调验证机构页与 Dashboard 机构卡数字一致
- 发布前检查机构状态映射和监控图表

## 回滚路径

1. 关闭扩展摘要聚合。
2. 机构详情仅展示基础资料与状态。
3. Dashboard 机构卡切回静态摘要快照。
