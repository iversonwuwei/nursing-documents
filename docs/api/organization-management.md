# 机构管理 API 草案

## 模块用途

服务机构列表、详情、床位概览和人员配置摘要。

## 建议接口

### 查询机构列表

- 方法: `GET`
- 路径: `/api/organizations`
- 用途: 返回机构名称、地址、电话、总床位和入住数

### 查询机构详情

- 方法: `GET`
- 路径: `/api/organizations/:organizationId`
- 用途: 获取负责人、床位结构、员工配置和承接压力摘要

### 查询床位摘要

- 方法: `GET`
- 路径: `/api/organizations/:organizationId/beds/summary`
- 用途: 返回占用、预留、空床和床位周转情况

### 查询员工配置摘要

- 方法: `GET`
- 路径: `/api/organizations/:organizationId/staff/summary`
- 用途: 返回在岗人数、关键岗位和压力判断

## 调用方

- 机构列表页
- 机构详情页
- AI 运营中心

## 兼容性

- 机构摘要字段需支持追加经营或风险标签。
- 床位和员工摘要应允许独立扩展，不与主详情强耦合。

## 回滚说明

如机构详情聚合接口不稳定，可回退为列表接口加多个摘要接口组合读取。
