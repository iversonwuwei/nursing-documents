# 治理级文档：低库存摘要

## 范围

面向物资列表页、Dashboard 库存卡片和 AI 补货建议，定义低库存摘要接口的口径、告警和回滚要求。

## 入口与调用方

- 方法: `GET`
- 路径: `/api/supplies/low-stock-summary`
- 主要调用方: 物资列表页、Dashboard 库存健康卡片、AI 补货建议
- 发布阶段: 先内部管理端，再开放给采购协同角色

## 依赖边界

- 主数据源: 物资库存表
- 扩展依赖: 安全库存规则、采购在途记录、AI 补货建议服务
- 约束: 只返回摘要与优先级，不直接创建采购单

## 成功判据

- 低库存物资数量和缺口优先级稳定可用
- Dashboard 与物资页展示口径一致
- AI 建议不可用时页面仍能展示低库存摘要

## 运行健康信号

- SLI: `p95_latency < 320ms`
- SLI: 成功率 `>= 99.7%`
- 业务指标: 低库存误报率 `< 1%`
- 业务指标: AI 建议缺失占比 `< 10%`

## 失败模式

- `400`: 分类参数非法
- `503`: 摘要服务不可用
- 降级策略: 只返回低库存数量和基础缺口，不返回补货建议

## 日志与监控

- 结构化日志字段: `category`、`organizationId`、`lowStockCount`、`aiSuggestionEnabled`、`degraded`
- 监控图表: 低库存数量、缺口金额、AI 建议缺失率
- 告警建议: 低库存摘要连续 3 次为空或误报率升高时触发 P2 告警

## 兼容性策略

- 新增优先级字段需保持旧字段继续可读
- 分类枚举扩展前同步页面筛选项
- AI 建议字段保持可选

## 验证门禁

- 契约测试覆盖多分类、空结果、AI 建议缺失、降级摘要
- 页面联调验证 Dashboard 和物资页口径一致
- 发布前校验低库存规则版本与告警阈值

## 回滚路径

1. 关闭 AI 补货建议服务。
2. 物资页仅展示基础库存摘要。
3. Dashboard 库存卡片切回静态快照。
