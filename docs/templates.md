# 模板说明

当前工程预置了以下模板，位于 `templates/` 目录：

- 需求文档模板
- 架构设计模板
- API 文档模板
- 会议纪要模板
- 发布检查清单模板
- 前端交付模板
- API 变更模板
- 回滚运行手册模板

推荐使用方式：

- 需求或范围澄清：先使用需求文档模板。
- UI、页面、交互、移动端改动：优先使用前端交付模板。
- 接口、DTO、BFF、服务契约改动：优先使用 API 变更模板。
- 发布前检查与异常处置：组合使用发布检查清单模板和回滚运行手册模板。

建议做法：

1. 从模板复制一份到对应文档目录。
2. 用真实项目名称、模块名和日期替换占位内容。
3. 文档评审通过后再作为后续实现和发布依据。
4. 涉及行为变更时，至少补齐验证门禁、健康信号和回滚路径。
