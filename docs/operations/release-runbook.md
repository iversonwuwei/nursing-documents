# 发布运行手册

## 适用范围

用于记录护理项目发布、验证、观察和回滚流程。

## 发布前检查

- 变更范围明确
- 影响模块明确
- 构建和静态检查通过
- 关键页面回归完成
- 文档已同步更新
- 回滚路径可执行

## 发布门禁

- 类型检查通过
- Lint 通过
- 目标模块验收通过
- 关键流程人工验证通过

## 观察指标

- 页面打开成功率
- 关键接口错误率
- 报警、任务、健康等核心流程是否异常
- AI 解释/建议页面是否出现异常空白或错误数据

## 回滚策略

- 前端回滚到上一稳定版本
- 禁用新增规则或入口
- 回退到人工流程和旧文档约定

## 记录要求

每次发布建议补充：

- 发布时间
- 发布人
- 变更摘要
- 验证结果
- 观察结论
- 是否触发回滚
